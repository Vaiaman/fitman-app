# Fitman (web-app)

Fitman voor iPhone en iedereen zonder Android-app: open **https://vaiaman.github.io/fitman-app/** in Safari en kies Deel › Zet op beginscherm.

Deze repository is een kopie van de Fitman-web-app uit de Fit-Woman-repository (daar wordt ontwikkeld). Elke update gaat naar beide adressen. Je gegevens blijven op je eigen telefoon.
